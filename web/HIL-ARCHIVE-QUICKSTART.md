# HIL-Archive 快速开始指南

> 5分钟快速体验人机协作规则筛选系统

---

## 🚀 立即开始

### Step 1: 启动应用

```bash
cd d:\ai-wolrld\web
npm run dev
```

访问: http://localhost:8000

### Step 2: 生成你的第一个世界

1. **输入核心异质点**:
   ```
   在这个世界中,谎言会增加说谎者的物理重力
   ```

2. **点击"Validate Core Premise"** → 等待验证完成

3. **输入艺术风格**:
   ```
   蒸汽朋克
   ```

4. **点击"Generate Rules"** → 等待生成 20 条规则

### Step 3: 体验标签与预测

生成完成后,你会看到:

- ✅ 每条规则带有 **紫色标签** (如: 循环、因果、神秘)
- ✅ 两个操作按钮:
  - **绿色对勾**: 确认喜欢的规则
  - **红色垃圾桶**: 删除不喜欢的规则

**尝试删除 3 条规则**:
- 找到带"残酷"或"矛盾"标签的规则
- 点击红色删除按钮
- 观察其他规则是否出现 **黄色/红色警告标识**

### Step 4: 保存你的世界

1. 在页面顶部输入存档名称:
   ```
   重力谎言世界 v1
   ```

2. 点击 **"保存存档"**

3. 看到成功提示: ✅ "存档保存成功!"

### Step 5: 管理存档

1. 点击 **"管理存档"** 按钮
2. 查看你的存档列表
3. 尝试:
   - **加载**: 恢复之前的世界
   - **删除**: 移除不需要的存档

## 🎨 功能亮点

### 1️⃣ 自动标签生成
每条规则自动打上 3-5 个标签:
- **情感基调**: 残酷、希望、神秘、荒诞
- **机制特性**: 循环、不可逆、连锁、资源依赖
- **叙事逻辑**: 矛盾、浮现、层级、分布式
- **逻辑结构**: 因果、概率、决定论、条件

### 2️⃣ 智能权重学习
系统会记住你的偏好:
- **删除规则** → 降低相关标签权重 (↓10%)
- **确认规则** → 提升相关标签权重 (↑5%)

### 3️⃣ 预测删除提示
基于你的历史选择,系统预测可能不喜欢的规则:
- 🟡 **黄色警告**: 删除评分 ≥ 60%
- 🔴 **红色危险**: 删除评分 ≥ 75%

### 4️⃣ 学科自动分类
规则自动映射到学科类别:
- 基于 **《普通高等学校本科专业目录》**
- 50+ 个二级专业类
- 支持学科覆盖率统计

### 5️⃣ 完整存档系统
- 保存完整世界状态 (规则、标签权重、验证结果)
- 随时加载历史存档
- 支持多个世界并行管理

## 💡 使用技巧

### 技巧 1: 快速筛选规则

**删除策略**:
- 先删除明显不喜欢的 5-10 条规则
- 观察预测警告,快速删除高风险规则
- 最后确认剩余的精品规则

### 技巧 2: 培养个性化审美

**标签权重训练**:
- 连续删除带"残酷"标签的规则 → 系统学会避免生成残酷规则
- 确认带"希望"标签的规则 → 系统倾向生成更多希望规则

### 技巧 3: 持续完善世界

**迭代优化**:
1. 保存第一版存档
2. 加载存档,继续生成新规则
3. 删除不合适的,保留精华
4. 保存为 v2 版本

### 技巧 4: 学科覆盖检查

**查看学科分布** (浏览器控制台):
```javascript
// 查看规则的学科分类
rules.map(r => ({
  rule: r.rule.substring(0, 30),
  disciplines: r.discipline_codes
}))
```

## ❓ 常见问题

### Q1: 标签为什么是中文?
A: 为了更好的可读性。系统同时使用英文 ID (如 `brutal`) 和中文名称 (如 "残酷")。

### Q2: 预测不准确怎么办?
A: 预测基于历史行为,需要删除 5-10 条规则后才会明显。继续使用会越来越准。

### Q3: 存档保存在哪里?
A: 保存在项目的 `archive/worlds/` 目录下,每个存档是一个 JSON 文件。

### Q4: 可以导出存档吗?
A: 可以!直接复制 `archive/worlds/{id}.json` 文件即可分享。

### Q5: 标签生成失败怎么办?
A: 检查:
1. DeepSeek/OpenAI API 密钥是否配置
2. 网络连接是否正常
3. 控制台错误日志
