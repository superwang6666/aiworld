# API 配置测试指南

## 步骤 1: 确认 .env 文件配置

确保你的 `.env` 文件包含以下内容之一：

**使用 DeepSeek (推荐):**
```
DEEPSEEK_API_KEY=sk-你的密钥
```

**或使用 OpenAI:**
```
OPENAI_API_KEY=sk-你的密钥
```

## 步骤 2: 启动服务器

服务器应该在后台运行。如果没有运行，执行：
```bash
npm run dev
```

## 步骤 3: 测试 API 连接

1. 打开浏览器访问: http://localhost:8000

2. 在页面上输入测试数据：
   - **Core Premise**: `一个谎言会增加物理重力的世界`
   - **Art Style**: `赛博朋克风格`

3. 点击 "GENERATE WORLD RULES" 按钮

4. 观察结果：
   - ✅ **成功**: 会显示 20 条规则卡片
   - ❌ **失败**: 会显示错误信息

## 步骤 4: 检查错误信息

如果出现错误，常见情况：

1. **"API Key not configured"**
   - 检查 `.env` 文件是否存在且包含正确的密钥
   - 确认密钥格式正确（通常以 `sk-` 开头）

2. **"Failed to generate rules"**
   - 检查 API 密钥是否有效
   - 确认 DeepSeek 账户有可用额度
   - 检查网络连接

3. **服务器错误 (500)**
   - 查看终端/控制台的错误日志
   - 确认 API 密钥格式正确

## 调试技巧

在浏览器开发者工具（F12）中：
- 打开 Network 标签
- 点击生成按钮
- 查看 `/api/generate` 请求的响应
- 查看响应中的错误信息
