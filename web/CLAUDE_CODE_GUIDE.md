# Claude Code 开发工作流指南

> 使用 Claude Code 进行高效开发的最佳实践

## 🤖 关于 Claude Code

Claude Code 是 Anthropic 官方的 AI 编程助手，可以帮助你：
- 编写和重构代码
- 查找和修复 bug
- 进行代码审查
- 解释复杂代码
- 优化性能

## 📋 开发工作流

### 1. 开始新功能

```bash
# 1. 描述需求
"我需要添加一个用户登录功能"

# 2. Claude 会：
#    - 询问具体需求（认证方式、UI 设计等）
#    - 探索现有代码结构
#    - 提出实现方案
#    - 等待你确认后开始实现

# 3. 实现过程中 Claude 会：
#    - 遵循项目的代码规范
#    - 使用现有的类型和工具函数
#    - 添加适当的错误处理
#    - 保持代码一致性
```

### 2. 代码审查

在提交代码前，让 Claude 审查：

```bash
# 方式 1：使用内置命令
/review

# 方式 2：直接询问
"请审查我刚才的修改，检查是否有问题"

# Claude 会检查：
# - 代码质量和最佳实践
# - 潜在的 bug 和安全问题
# - 性能优化建议
# - 代码规范遵守情况
```

### 3. 重构代码

```bash
# 明确重构目标
"请重构 app/page.tsx，将状态管理逻辑提取为自定义 Hook"

# Claude 会：
# 1. 分析现有代码
# 2. 提出重构方案
# 3. 等待确认
# 4. 执行重构
# 5. 删除旧代码
# 6. 验证功能正常
```

### 4. 修复 Bug

```bash
# 描述问题
"用户点击提交按钮后，表单没有响应"

# Claude 会：
# 1. 查看相关代码
# 2. 分析可能的原因
# 3. 提出修复方案
# 4. 实施修复
# 5. 建议添加测试
```

### 5. 代码清理

```bash
# 定期清理
"帮我检查项目中是否有未使用的代码"

# Claude 会：
# - 运行 ts-prune 检测未使用的导出
# - 查找重复代码
# - 识别废弃文件
# - 提出清理建议
```

## ✅ 最佳实践

### 1. 明确的需求描述

❌ 不好的描述：
```
"改一下登录功能"
```

✅ 好的描述：
```
"修改登录功能：
1. 添加'记住我'选项
2. 登录失败时显示具体错误信息
3. 添加密码强度提示"
```

### 2. 分步骤进行

对于复杂任务，分解为小步骤：

```bash
# 步骤 1
"首先，帮我分析现有的认证系统架构"

# 步骤 2
"好的，现在添加 JWT token 刷新机制"

# 步骤 3
"最后，添加自动登出功能"
```

### 3. 及时反馈

如果 Claude 的实现不符合预期，及时说明：

```bash
"这个实现有点复杂，能否简化一下？"
"我希望使用 Context API 而不是 Redux"
"这个命名不够清晰，能改成更具描述性的吗？"
```

### 4. 利用项目上下文

Claude 可以访问整个项目，充分利用这一点：

```bash
"参考 GameRecommendView 的实现方式，创建一个类似的 UserProfileView"
"使用和 ValidationPage 相同的样式风格"
"遵循 lib/rules/ 中的代码组织方式"
```

## 🚫 注意事项

### 不要做的事

1. **不要盲目接受所有建议**
   - 审查 Claude 的代码
   - 确保符合项目需求
   - 测试功能是否正常

2. **不要一次性要求太多**
   - 大任务分解为小步骤
   - 每步确认后再继续

3. **不要忽略代码规范**
   - 提醒 Claude 遵循 CODE_STANDARDS.md
   - 检查导入顺序、命名等

4. **不要跳过测试**
   - 要求 Claude 添加测试
   - 本地验证功能

### 应该做的事

1. **明确表达意图**
   - 说明"为什么"而不只是"做什么"
   - 提供上下文信息

2. **保持对话连贯**
   - Claude 记住之前的对话
   - 可以引用之前讨论的内容

3. **要求解释**
   - 不理解的代码要求解释
   - 了解实现的原理

4. **提供反馈**
   - 好的实现给予肯定
   - 不满意的地方说明原因
