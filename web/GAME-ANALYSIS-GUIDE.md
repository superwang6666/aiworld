# 游戏类型分析功能使用指南

## 功能概述

游戏类型分析是世界观构建引擎的第0步（可选），帮助你从代表作游戏中提取核心元素，为创建独特的世界观提供参考。

## 使用流程

### 1. 搜索游戏

**推荐搜索方式：**

✅ **具体游戏名称**（效果最好）
- 示例：`Hades`, `Elden Ring`, `Dead Cells`, `Hollow Knight`
- 优点：精准匹配，返回高质量结果

✅ **知名游戏系列**
- 示例：`Dark Souls`, `Zelda`, `Metroid`, `Castlevania`
- 优点：找到系列代表作

⚠️ **游戏类型标签**（结果质量参差不齐）
- 示例：`roguelike`, `metroidvania`, `soulslike`
- 注意：可能返回低质量独立游戏，建议搭配具体游戏名

### 2. 选择游戏

- 建议选择 **2-5 个游戏** 进行对比分析
- 优先选择有 **Metacritic 评分** 的游戏（质量更高）
- 可以选择同类型游戏找共性，或不同类型游戏找创新点

### 3. AI 分析

AI 会提取以下信息：
- **美术风格** - 视觉呈现特征
- **核心玩法** - 游戏机制
- **叙事结构** - 故事讲述方式
- **独特特征** - 与其他游戏的区别
- **世界观启发** - 与七大法则相关的构建灵感

### 4. 应用到世界观

点击"应用到世界观构建"后，提取的启发会自动填充到核心设定输入框。

## 常见问题

### Q: 搜索结果质量不好？
**A:** 尝试以下方法：
- 使用英文游戏全名（如 `The Witcher 3` 而非 `巫师3`）
- 搜索具体游戏而非类型
- 添加平台信息（如 `PC roguelike`）

### Q: 找不到某个游戏？
**A:** 可能原因：
- RAWG 数据库未收录（小众/新游戏）
- 游戏名称拼写错误
- 尝试搜索英文原名

### Q: 可以跳过这一步吗？
**A:** 可以！点击底部"跳过游戏分析，直接开始"即可。

## API 配置（可选）

### RAWG API 密钥

**免费额度：** 20,000 次/月

**注册步骤：**
1. 访问 https://rawg.io/apidocs
2. 注册账号
3. 获取 API Key
4. 在项目根目录的 `.env` 文件中添加：
   ```
   RAWG_API_KEY=your-key-here
   ```

**注意：** 即使不配置 API 密钥也可以使用，但可能有更严格的速率限制。

## 示例：分析 Roguelike 游戏

### 输入
搜索并选择：
- Hades
- Dead Cells
- Slay the Spire

### AI 输出示例
**提取的核心元素：**
- 永久死亡 + 渐进式解锁
- 随机生成关卡
- 快节奏战斗
- 角色成长系统

**世界观启发：**
- **Time（时间）**: 循环时间概念，死亡作为进步手段
- **Scarcity（稀缺）**: 资源在循环中的平衡机制
- **Power（权力）**: 通过死亡获得的知识和能力

## 技术细节

- **数据来源**: RAWG Video Games Database
- **AI 模型**: DeepSeek / GPT-4o-mini
- **缓存策略**: 搜索结果缓存 1 小时
- **搜索算法**: 按人气排序，过滤低质量结果（评分 < 2.5）
