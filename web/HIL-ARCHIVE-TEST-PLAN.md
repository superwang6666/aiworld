### ✅ Phase 2: 标签生成测试

#### 2.1 生成规则并打标签

**步骤**:
1. 进入应用,输入核心异质点: "时间会撒谎"
2. 验证前提
3. 选择艺术风格: "蒸汽朋克"
4. 生成规则

**检查点**:
- [ ] 每条规则显示 3-5 个紫色标签徽章
- [ ] 控制台显示: "标签生成完成: 20 条规则已打标签"
- [ ] 鼠标悬停标签显示权重百分比 (~50%)

**预期标签示例**:
- 循环、神秘、时间敏感、因果、矛盾

#### 2.2 混合标签测试

**检查点**:
- [ ] 至少有 70% 规则包含预定义标签
- [ ] 部分规则包含 LLM 生成的特殊标签
- [ ] 控制台无标签生成错误

---

### ✅ Phase 3: 权重反馈测试

#### 3.1 删除规则测试

**步骤**:
1. 找到一条带"残酷"标签的规则
2. 点击红色删除按钮
3. 观察其他带"残酷"标签的规则

**检查点**:
- [ ] 规则被标记为已删除 (删除按钮变灰)
- [ ] 控制台显示: "标签权重已更新,删除评分已重新计算"
- [ ] 其他带相同标签的规则预测评分上升
- [ ] 部分规则出现黄色/红色警告标识

#### 3.2 权重衰减验证

**步骤**:
1. 连续删除 3 条带相同标签的规则
2. 打开浏览器控制台
3. 查看 tagWeights 状态 (使用 React DevTools)

**检查点**:
- [ ] 该标签的 deletion_count 增加到 3
- [ ] 该标签的 weight 降低 (约 0.5 → 0.45 → 0.40)
- [ ] 其他未删除标签的权重保持 0.5

---

### ✅ Phase 4: 预测删除测试

#### 4.1 "猜你想删"功能

**步骤**:
1. 删除 5 条规则 (选择特定类型,如"残酷"、"矛盾")
2. 观察未删除的规则
3. 查找带黄色/红色警告的规则

**检查点**:
- [ ] 至少 2-3 条规则显示黄色警告标识
- [ ] 警告规则下方显示提示文本
- [ ] 提示文本包含删除评分百分比
- [ ] 评分 ≥ 60% 显示黄色警告
- [ ] 评分 ≥ 75% 显示红色危险标识

#### 4.2 确认规则降低评分

**步骤**:
1. 确认一条高风险规则 (黄色警告)
2. 观察警告是否消失或降级

**检查点**:
- [ ] 控制台显示权重更新日志
- [ ] 规则的删除评分下降
- [ ] 警告标识可能消失 (如果评分降到 60% 以下)

### ✅ Phase 7: 完整工作流测试

#### 7.1 端到端流程

**场景**: 完整的世界构建与存档流程

**步骤**:
1. **输入前提**: "谎言会增加物理重力"

7. **保存存档**: 命名为"重力谎言世界"
8. **清空页面**: 刷新浏览器
9. **加载存档**: 从存档列表恢复
10. **验证状态**: 确认所有数据正确恢复

**检查点**:
- [ ] 所有步骤无错误
- [ ] 标签权重在删除后下降

- [ ] 存档完整保存和恢复

## 已知限制

1. **标签语言**: 中文标签可能影响匹配准确性
2. **LLM 依赖**: 标签生成依赖 DeepSeek/OpenAI API
3. **单用户设计**: 不支持多用户隔离
4. **文件存储**: 使用本地 JSON 文件,不适合大规模部署
