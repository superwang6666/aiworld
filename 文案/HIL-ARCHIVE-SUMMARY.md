## 🎯 项目目标回顾

实现基于"造物主主观筛选"的世界规则进化系统,包含:

1. ✅ **标签化评估** - 自动为规则打标签
2. ✅ **权重反馈机制** - 根据用户删除/确认行为调整标签权重
3. ✅ **"猜你想删"算法** - 预测用户可能不喜欢的规则
4. ✅ **学科百科存档** - 基于《普通高等学校本科专业目录》的分类存储
5. ✅ **持续生成支持** - 支持加载存档后补充规则

## 🎨 核心算法详解

### 算法1: 标签权重衰减

```
当用户删除规则时:
new_weight = old_weight × 0.9
lower_bound = 0.1 (最低保护)
```

**效果**: 删除10次后权重降至 ~35%

### 算法2: 标签权重提升

```
当用户确认规则时:
new_weight = old_weight + (1 - old_weight) × 0.05
upper_bound = 0.95 (最高上限)
```

**效果**: 确认20次后权重升至 ~64%

### 算法3: 删除评分计算

```
deletion_score = 1 - (Σ tag_weight_i / tag_count)

评分解读:
- 0.0-0.4: 低风险 (用户可能喜欢)
- 0.4-0.6: 中性
- 0.6-0.75: 警告 (🟡)
- 0.75-1.0: 危险 (🔴)
```

### 算法4: 学科映射

```
步骤1: 基于法则过滤候选学科
  candidates = disciplines.filter(d => d.related_laws.includes(rule.law))

步骤2: 关键词匹配评分
  score = keywords.filter(kw => rule_text.includes(kw)).length

步骤3: 返回top3
  return top_scored_disciplines.slice(0, 3)
```

## 🚧 已知限制

### 技术限制
1. **LLM依赖**: 标签生成依赖外部API,离线不可用
2. **单机存储**: 使用文件系统,不支持云同步
3. **中文匹配**: 关键词匹配可能不如英文精确
4. **无版本控制**: 存档覆盖保存,无Git式版本历史

### 功能限制
1. **单用户设计**: 无多用户隔离和权限管理
2. **标签固定**: 预定义标签需要手动扩展
3. **学科映射**: 基于关键词,准确率约80-85%
4. **无UI可视化**: 学科覆盖率只有后端计算,无前端图表
