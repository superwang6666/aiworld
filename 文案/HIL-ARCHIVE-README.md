## 🌟 核心功能

### 1️⃣ 自动标签化评估
每条生成的规则自动打上**3-5个语义标签**:

```typescript
规则: "所有钟表指针会随机跳跃"
标签: #循环 #时间敏感 #神秘 #矛盾
```

**4大标签类别**:
- 🎭 **情感基调**: 残酷、希望、神秘、荒诞...
- ⚙️ **机制特性**: 循环、不可逆、连锁、资源依赖...
- 📖 **叙事逻辑**: 矛盾、浮现、层级、分布式...
- 🧮 **逻辑结构**: 因果、概率、决定论、条件...

### 2️⃣ 智能权重反馈
系统根据你的选择**动态调整标签权重**:

```
删除规则 → 标签权重 -10% → 系统学会避免
确认规则 → 标签权重 +5%  → 系统倾向生成
```

**效果**: 删除10次后,相关标签权重降至~35%,预测系统自动识别高风险规则。

### 3️⃣ "猜你想删"预测
基于标签权重智能预测可能不喜欢的规则:

- 🟡 **黄色警告** (评分≥60%): 建议审查
- 🔴 **红色危险** (评分≥75%): 强烈建议删除

**节省时间**: 从手动筛选100条 → 重点审查20条高风险

### 4️⃣ 学科百科存档
基于**《普通高等学校本科专业目录》**自动分类:

- 📚 **50+个二级专业类**: 哲学、经济、法学、理学、工学...
- 🗺️ **自动映射**: 规则根据内容自动归类到相关学科
- 📊 **覆盖统计**: 实时显示学科覆盖率和缺口
- 💡 **智能提示**: "历史学类缺失,建议补充"

### 5️⃣ 完整存档系统
保存完整的世界构建状态:

```json
{
  "name": "重力谎言世界",
  "rules": [...],           // 所有规则(含删除状态)
  "tag_weights": {...},     // 标签权重快照
  "discipline_coverage": [...], // 学科覆盖统计
  "validation_result": {...}    // 验证结果
}
```

**支持**: 保存、加载、列表、删除、版本管理

2. 点击"保存存档"
3. 点击"管理存档"随时加载

## 🎯 核心算法

### 算法1: 标签权重更新

**删除时衰减**:
```
new_weight = old_weight × 0.9
lower_bound = 0.1
```

**确认时提升**:
```
new_weight = old_weight + (1 - old_weight) × 0.05
upper_bound = 0.95
```

### 算法2: 删除评分预测

```
deletion_score = 1 - (Σ tag_weight_i / tag_count)

解读:
- 0.0-0.4: 低风险 (用户可能喜欢)
- 0.4-0.6: 中性
- 0.6-0.75: 警告 🟡
- 0.75-1.0: 危险 🔴
```

### 算法3: 学科映射

```python
# 伪代码
candidates = filter_by_law(rule.law)
scores = match_keywords(rule.text, candidates.keywords)
return top_3(scores)
```
