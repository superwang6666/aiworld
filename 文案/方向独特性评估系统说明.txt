# 方向独特性评估系统说明

## 📋 概述

该系统用于评估多米诺效应分析中各个方向（Law Impacts）的独特性和质量。评估规则固定在配置文件中，无需用户手动输入。

## 🗂️ 文件结构

### 1. 配置文件：`config/evaluation-rules.ts`

这是核心配置文件，定义了所有评估规则。

**主要内容：**

- **6 个评估规则维度：**
  1. **非线性因果关系** (权重: 1.5)
  2. **多感官维度影响** (权重: 1.2)
  3. **涌现特性** (权重: 1.8)
  4. **社会结构重塑** (权重: 1.3)
  5. **悖论生成** (权重: 1.4)
  6. **可扩展性影响** (权重: 1.0)

- **评分标准：**
  - 0-30分: 不符合标准
  - 31-60分: 部分符合标准
  - 61-85分: 强烈符合标准
  - 86-100分: 例外地符合标准

- **最低合格分数：** 60分

### 2. API 端点：`app/api/evaluate-directions/route.ts`

自动从配置文件读取评估规则，调用 AI 进行评估。

### 3. 前端组件：`components/ValidationReport.tsx`

用户界面，显示评估按钮和结果。

## 🎯 功能特性

### 自动评估
- 用户点击"Evaluate Directions"按钮
- 系统自动应用预定义的 6 个评估维度
- AI 根据配置文件中的规则进行评分

### 智能过滤
- 评估完成后，可选择只显示合格方向（≥60分）
- 显示合格方向数量统计

### 详细反馈
- 每个方向显示独特性评分（0-100）
- 列出该方向通过的具体评估标准
- 颜色编码：
  - 🟢 绿色（80-100）：优秀
  - 🔵 蓝色（60-79）：合格
  - 🟡 黄色（40-59）：部分合格
  - 🔴 红色（0-39）：不合格

## ⚙️ 如何修改评估规则

只需编辑 `config/evaluation-rules.ts` 文件：

```typescript
export const EVALUATION_CONFIG: EvaluationConfig = {
  version: '1.0.0',
  minPassingScore: 60,  // 修改最低合格分数

  rules: [
    {
      id: 'your-rule-id',
      name: '你的规则名称',
      description: '规则描述',
      criteria: [
        '具体标准1',
        '具体标准2',
        '具体标准3',
      ],
      weight: 1.5,  // 规则权重
    },
    // 添加更多规则...
  ],

  systemPrompt: '...'  // 可以自定义 AI 的系统提示
};
```

## 🔧 未来扩展建议

1. **规则权重应用**：目前权重已定义但未在评分计算中使用，可以实现加权评分系统
2. **自定义阈值**：允许用户调整合格分数阈值
3. **规则启用/禁用**：添加开关来选择性启用某些规则
4. **评估历史**：保存历史评估结果用于对比分析
5. **批量评估**：支持一次性评估多个前提的方向

## 📝 使用流程

1. 用户输入 Core Premise
2. 系统验证并生成 7 Laws 的多米诺效应分析
3. 在 Validation Report 页面，点击 "Evaluate Directions" 按钮
4. 系统根据 `evaluation-rules.ts` 中的规则自动评估所有方向
5. 显示评分结果和通过的标准
6. 可选择只查看合格的方向（≥60分）

## ⚠️ 注意事项

- 评估规则是固定的，存储在代码库中
- 修改规则需要重新部署应用
- AI 评估结果可能有一定的随机性（temperature=0.7）
- 评分标准应该保持严格，大多数方向应在 40-70 分范围内
