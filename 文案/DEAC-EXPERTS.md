# DEAC 核心专家系统说明
**6个专家方向 - 完整覆盖世界构建的7大法则**

版本: 2.0.0 (更新于 2026-01-19)

---

## 概述

DEAC (Dynamic Expert Agent Cluster) 系统现已升级为**6个核心专家**,提供更全面、更深入的世界构建分析。新体系覆盖了从物理基础到权力结构的全方位视角。

---

## 6个核心专家

### 1. 地质学与气候学家 (The Foundation) 🌍

**泰拉·格奥教授**

**专业领域:**
- 地质构造与板块运动
- 气候系统与大气动力学
- 水文循环与海洋学
- 矿物资源与地质分布
- 自然灾害(地震、火山、飓风)
- 土壤科学与地表生态
- 地球化学与元素循环

**法则覆盖:**
- 主要: Space (空间), Survival (生存)
- 次要: Scarcity (稀缺), Time (时间)

**推理风格:** 分析型 (Analytical)

**角色:** 作为"基础"专家,分析世界的物理框架和环境条件如何塑造一切可能性。

---

### 2. 人类学家与社会学家 (The Culture) 🎭

- 宗教信仰与精神实践
- 社会变迁与文化适应

**法则覆盖:**
- 主要: Cognition (认知), Metaphysics (形而上)
- 次要: Power (权力), Time (时间)

**推理风格:** 整体型 (Holistic)

**角色:** 作为"文化"专家,分析人类如何为世界赋予意义,以及社会如何组织自身。

- 主要: Cognition (认知), Power (权力)

**推理风格:** 推测型 (Speculative)

**角色:** 作为"声音"专家,分析语言如何塑造思维、传递权力和表达世界观。

## 推理风格分布

- **Analytical** (分析型): 地质气候, 历史考古
- **Holistic** (整体型): 人类社会
- **Speculative** (推测型): 语言学
- **Empirical** (实证型): 经济学
- **Adversarial** (批判型): 政治军事

多样化的推理风格确保从不同角度审视异质点,避免思维盲区。

## 技术实现

### 配置文件位置
```
lib/experts/core/
├── geology-climate.json          # 地质气候专家
├── anthropology-sociology.json   # 人类社会专家
├── linguistics.json              # 语言学专家
├── economics.json                # 经济学专家
├── history-archaeology.json      # 历史考古专家
└── politics-military.json        # 政治军事专家
```

### 自动激活逻辑

专家根据以下规则自动激活:
1. 提取验证结果中的法则影响 (`lawImpacts`)
2. 为每个专家评分:
   - 主要法则匹配: +2分
   - 次要法则匹配: +1分
3. 按分数排序,激活得分最高的专家
4. 最多同时激活5位专家

### 特殊专家补充

当核心专家无法覆盖特定异质点时,Prompt Architect Agent 会自动生成特殊专家:
- 魔法系统物理学
- 时间力学与因果关系
- 心理学与梦境逻辑
- 数字物理学与虚拟现实
- 多维空间理论
- 生命延续与灵魂理论

## 与主系统的集成

### 工作流程

1. **步骤2: 验证前提** → 生成 `ValidationResult` (包含 `lawImpacts`)
2. **触发DEAC** → 后台异步运行,不阻塞用户
3. **激活专家** → 根据法则影响自动选择
4. **收集分析** → 并行查询所有专家
5. **综合洞察** → 识别共识、分歧、涌现洞察
6. **展示结果** → 在验证报告下方显示专家面板

### UI组件

`ExpertInsightsPanel` 显示:
- 激活的专家数量
- 每位专家的分析摘要
- 警告和建议
- 综合共识和风险评估
- 生成的特殊专家(如有)

## 配置文件结构

每个专家配置包含:

```json
{
  "id": "expert-id",
  "version": "1.0.0",
  "name": "专家名称",
  "domain": "专业领域",
  "knowledge_scope": ["知识点1", "知识点2", ...],
  "law_mapping": {
    "primary": ["Law1", "Law2"],
    "secondary": ["Law3", "Law4"]
  },
  "prompt_template": "系统提示词模板...",
  "reasoning_style": "analytical|holistic|speculative|empirical|adversarial",
  "expertise_depth": 7,
  "specialization_tags": ["标签1", "标签2"],
  "created_by": "system"
}
```

## 扩展指南

### 添加新核心专家

1. 在 `lib/experts/core/` 创建新JSON文件
2. 确保法则映射不与现有专家完全重复
3. 选择独特的推理风格
4. 重启应用即可自动加载

### 修改现有专家

直接编辑对应的JSON文件,系统会在下次启动时自动加载新配置。
