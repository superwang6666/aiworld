2. 性能优化技巧
// ✅ 好的做法
- 使用 CSS transform（GPU加速）
- 限制粒子数量（大20个 + 小40个）
- 大光晕用极大 blur（减少重绘）
- 静态层不用 Motion 组件

// ❌ 避免
- 过多粒子（>100个会卡顿）
- 小 blur 值（<30px 反而更耗性能）
- 所有元素都用 Motion
